# 👤 Sistema de Cadastro de Clientes

Sistema web desenvolvido para gerenciamento de clientes, permitindo realizar operações completas de cadastro, consulta, edição e exclusão de dados (CRUD). O projeto foi criado utilizando PHP, MySQL, HTML, CSS e JavaScript, com foco na integração entre front-end e back-end.

---

## 📌 Sobre o Projeto

O objetivo deste sistema é facilitar o gerenciamento de clientes por meio de uma interface simples, intuitiva e responsiva. A aplicação permite armazenar e manipular informações de clientes de forma prática, aplicando conceitos fundamentais do desenvolvimento web.

Este projeto foi desenvolvido como atividade acadêmica para aplicação dos conceitos de CRUD, validação de formulários e comunicação cliente-servidor.

---

## 🚀 Funcionalidades

- ✅ Cadastro de clientes  
- ✅ Listagem de clientes cadastrados  
- ✅ Edição de informações  
- ✅ Exclusão de registros  
- ✅ Validação de formulários  
- ✅ Interface responsiva
